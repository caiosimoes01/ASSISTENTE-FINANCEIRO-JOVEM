💡 DICAS DE USO
═════════════════════════════════════════════════════════════════════════

✅ Importe sempre do barrel export:
   import { BentoCard, SliderField, GrowthChart, Navigator } 
     from '@/components/young-finance';

✅ Use as classes utilitárias da paleta:
   className="bg-youfing-secondary text-accent shadow-youfing-glow"

✅ Combine componentes para criar layouts:
   <div className="grid grid-cols-3 gap-4">
     <BentoCard ... />
     <BentoCard ... />
     <BentoCard highlight={true} />
   </div>

✅ Adicione ícones com lucide-react:
   import { Zap, BarChart2, Target, Calculator } from 'lucide-react';
   <BentoCard icon={<Zap size={20} />} ... />

✅ Use SliderField para entrada controlada:
   const [value, setValue] = useState(0);
   <SliderField value={value} onChange={setValue} ... />
